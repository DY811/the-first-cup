## Notes
- Recording choice: we matched the language code inside each filename (`LL-Q…(iso639-3)` for Lingua Libre, `Xx-` for Wiktionary). We did not trust search ranking, which returned wrong-language recordings.
- Phonetic transcriptions come from the English Wiktionary entry for each word, not from us. Hebrew has no transcription there, so that card shows none.
